Python's syntax.
Compiled, checked, fast.

Tacqor is a statically typed language that reads like Python, handles failure like Rust, and runs as bytecode or native machine code — all from one 4 MB executable with no runtime to install.

git clone https://github.com/tacqor/tacqor
cd tacqor && sh install.sh
or download a release 
$ cat app.tq
def parse(text: str) -> Result[i64, str]:
    match parse_int(strip(text)):
        case Some(n):
            return Ok(n)
        case None:
            return Err(f"not a number: {text}")

def main():
    let total: i64 = parse("21") * 2
    print(total)

$ tacqor check app.tq
app.tq:9:22: error: arithmetic expects i64 or f64, found Result[i64, str]
        let total: i64 = parse("21") * 2
                         ^~~~~

# fix: let total = unwrap_or(parse("21"), 0) * 2
$ tacqor check app.tq
app.tq: OK
$ tacqor build --native app.tq -o app && ./app
42

What you get

A small language with a complete toolchain. Nothing to configure, no package to install before the first program runs.

Errors before the program runs
Static types with inference, Option and Result instead of null and exceptions, exhaustive match, the ? operator, and integer arithmetic that is overflow-checked everywhere — in the VM and in native code alike.
Two backends, one meaning
tacqor app.tq runs instantly in the bytecode VM. tacqor build --native turns the same program into machine code through the system C++ compiler. Every feature program is tested through both and must produce identical output.
One executable does everything
Check, test, run, compile, package into a self-contained binary, generate C++, disassemble, scaffold a project, manage packages, and open a REPL — one 4 MB static binary plus a standard library written in Tacqor.
Generics, closures, traits
Generic functions and structs monomorphized like Rust, closures that capture by value, traits with static dispatch through bounds and dynamic dispatch through trait-typed values. No inheritance to untangle.
Memory you don't manage
Reference counting frees objects the moment they are unreachable; an automatic cycle collector takes care of the rest. No ownership annotations, no pauses to tune.
Batteries that are source code
Lists, strings, math, collections, JSON, an HTTP/1.1 server and client, and a test harness — all written in Tacqor, all readable, all on the import path from the first run.

If you write Python, you already read Tacqor

Same shape, with the types on the signature and the failure in the return type.

Measured, not promised

Same algorithm in each language, best of nine runs on one machine, seconds. Sources and the runner are in benchmarks/; the method is in the performance report.

The toolchain, in one line each

tacqor app.tqcompile and run in the VM
tacqor check app.tqtype-check and warn, without running
tacqor test tests.tqrun every def test_*()
tacqor build app.tq -o appself-contained executable with the VM embedded
tacqor build --native app.tq -o appmachine code through the system C++ compiler
tacqor compile app.tq -o app.tqbportable bytecode
tacqor dump app.tqdisassemble
tacqor emit app.tq -o app.cppthe C++ the native build compiles
tacqor new projectscaffold a project with a test
tacqor add URLinstall a package from any git repository or folder
tacqor replinteractive scratchpad
tacqor diagnose --stdinJSON diagnostics for editors; the VS Code extension uses it
