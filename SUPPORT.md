# Getting help

| I want to… | Go to |
|---|---|
| Learn the language | [`TOUR.md`](TOUR.md), then [`docs/COOKBOOK.md`](docs/COOKBOOK.md) |
| Look something up | [`LANGUAGE.md`](LANGUAGE.md), [`STDLIB.md`](STDLIB.md), [`docs/TOOLING.md`](docs/TOOLING.md), [`docs/ERRORS.md`](docs/ERRORS.md) |
| Understand a compiler message | [`docs/ERRORS.md`](docs/ERRORS.md) lists every one with the fix |
| Ask a question or show what I built | [Discussions](https://github.com/tacqor/tacqor/discussions) |
| Report a bug | [New issue → Bug report](https://github.com/tacqor/tacqor/issues/new/choose) with the smallest program that shows it |
| Propose a feature | [New issue → Feature proposal](https://github.com/tacqor/tacqor/issues/new/choose); read [`ROADMAP.md`](ROADMAP.md) first |
| Report a security problem | [`SECURITY.md`](SECURITY.md) — privately, not in a public issue |
| Contribute | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

Before asking, run `tacqor check` on your program: the diagnostics name the file, line and column and usually say what to change. Include `tacqor --version` and your platform in every report.
